# 🌸 Bouquet App

Aplikasi manajemen penjualan bouquet berbasis web untuk toko bunga.

---

## 🛠️ Tech Stack

**Frontend:**
- React.js

**Backend:**
- Node.js + Express.js

**Database:**
- PostgreSQL (Supabase)

---

## 📁 Struktur Project
