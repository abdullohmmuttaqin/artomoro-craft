# 🌸 Bouquet App

Aplikasi manajemen penjualan bouquet berbasis web untuk toko bunga.

## 🛠️ Tech Stack

**Frontend:**
- React.js

**Backend:**
- Node.js + Express.js

**Database:**
- PostgreSQL (Supabase)

## 📁 Struktur Project

```
bouquet-app/
├── backend/ # REST API (Node.js + Express)
└── frontend/ # Web UI (React.js) — coming soon
```
